# Project Requirements

This document summarizes the technical requirements, workflows, and standards extracted from the `Information - Pantima.xlsx` file for the **Developer** role.

## 1. Project Scope & Priority
- **Target Markets:** En_US (Primary Priority), pt_BR, fr_FR, zh_CN, ja_JP, ko_KR, etc.
- **Data Type Priority:**
    1. **Notes (Personal Memos):** Absolute top priority.
    2. **Files / Webpages / Screenshots:** Secondary priority.
    3. **Emails / Messages / Voicemail Transcripts.**

## 2. Technical Workflow
Data Production Cycle: `Creator` -> `Dev` -> `Anno` -> `Detect AI` -> `Script`.
### Developer Responsibilities:
- **Conversion Tool Development:** Finalize scripts in `src/text_converter/` to standardize raw data.
- **Metadata Management:** Ensure scripts support the new metadata structure (`primary_category` and `secondary_category`).
- **QA Automation:** Implement scripts for automated checks (AI detection ratio, phone number formatting, deduplication).

## 3. Data Format Standards
| Data Type | Output Format | Technical Requirements |
| :--- | :--- | :--- |
| **Notes / Memos** | `.txt` | Natural language, personal content, high context. |
| **Messages** | `.txt` | Clear sender/recipient. Group chats allowed; no mass marketing/spam. |
| **Emails** | `.eml` | Must be native `.eml` files. Focus on personal/business exchanges. |
| **Voicemail** | `.txt` (Transcript) | **No audio files**. Transcriptions may include `<inhale>`, `<um>`, `<uh>`. |
| **Files** | `.pdf`, `.rtf` | Contracts, invites, confirmations, receipts, etc. |
| **Webpages** | `.html` | Saved as a single HTML file. |
| **Photos** | `.jpg`, `.png` | Text-focused images (posters, flyers, business cards). |

## 4. Category-Specific Rules
### 4.1. Contact
- Mandatory: At least one form of contact (Phone/Email/Address) + Name.
- Context: Must include a reason for the contact (e.g., "Plumber - call for kitchen leaks").

### 4.2. Event
- Mandatory Fields: **Title** (Event name), **Location** (Address/City), **Temporal** (Date/Time).

### 4.3. People & Relationships
- Focus: Documents proving relationships (Offer letters, landlord letters, emergency contact forms, registration portals).

### 4.4. Topics of Interest
- 18 categories (Sports, Food, Technology, Travel, etc.).
- **Privacy Policy:** Absolutely NO personal health details (medical conditions, insurance). Only Fitness or general dietary data allowed.

## 5. Quality Assurance (KPIs)
- **AI Detection:** Questionable content generated by AI must be **< 20%**.
- **Phone Numbers:** Prefer the **+1** prefix for US locale.
- **Uniqueness:** Zero duplication across participants or within batches.
- **Quality:** Content must be meaningful and descriptive (no minimal/low-context info).

## 6. Updated Metadata Structure
- `primary_category` (Required): The most accurate category label.
- `secondary_category` (Optional): Meaningful but weaker association.
- `Participant ID`: Unique identifier for the person providing the data.
- `Timestamp`: Approximate collection time.
